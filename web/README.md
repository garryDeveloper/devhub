# DevHub — web

React 18 + TypeScript + Vite. See [`docs/tech-specs/frontend-web-architecture.md`](../docs/tech-specs/frontend-web-architecture.md)
for the folder structure and conventions, and [`docs/tech-specs/local-development.md`](../docs/tech-specs/local-development.md)
for full local setup.

## Commands

```bash
npm install
cp .env.example .env.local   # adjust VITE_API_URL if the API isn't on the default port
npm run dev                  # http://localhost:5173
npm run lint
npm run build
```
